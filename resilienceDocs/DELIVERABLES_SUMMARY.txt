### 📊 Error Handling Flow

```
API Call
  ↓
  ├─→ Success ✓
  │   └─→ CircuitBreaker.CLOSED
  │       failure_count = 0
  │
  └─→ Failure ✗
      ↓
      ├─→ Network timeout
      │   └─→ RetryableError
      │       ├─→ if attempts < max: sleep + retry
      │       └─→ if attempts == max: log to .failures/
      │
      ├─→ Rate limit (429)
      │   └─→ RetryableError
      │       └─→ (same as above)
      │
      ├─→ Server error (5xx)
      │   └─→ RetryableError
      │       └─→ (same as above)
      │
      └─→ Permanent error (401, 404, validation)
          ├─→ PermanentError
          ├─→ Fail immediately (no retries)
          └─→ Log to .failures/
```

### 💡 Key Improvements

#### Before (Original)
```python
# One attempt, crashes on any error
def upload_to_archive(...):
    from internetarchive import upload
    upload(identifier, files=[str(file)], ...)  # Fail → crash
    return identifier
```

#### After (Improved)
```python
@retry_with_backoff(ARCHIVE_RETRY_CONFIG)  # Retry up to 8 times
def _upload_to_archive_impl(...):
    upload(identifier, files=[str(file)], ...)

def upload_to_archive(...):
    try:
        return archive_breaker.call(_upload_to_archive_impl, ...)
    except Exception as e:
        failure_log.record_failure(...)  # Log for recovery
        return None  # Continue, don't crash
```

**Result:** Transient failures retry automatically. Permanent failures fail fast. All failures logged.

### 📈 Retry Strategy

**Archive.org** (unstable, slow):
```
Attempts: 8
Delays: 3s → 6s → 12s → 24s → 48s → 96s → 120s → 120s
Total: ~390 seconds (6.5 minutes worst case)
```

**Buzzsprout** (more reliable):
```
Attempts: 6
Delays: 2s → 4s → 8s → 16s → 32s → 64s
Total: ~130 seconds worst case
```

**Permanent errors** (invalid input, auth):
```
Attempts: 1 (fail immediately, no retry)
```

### 🚨 Circuit Breaker

**State Machine:**
```
CLOSED
  ↓ (3 failures)
OPEN (stop trying)
  ↓ (wait 10 min)
HALF_OPEN (test recovery)
  ├─ Success → CLOSED (resume)
  └─ Failure → OPEN (try again in 10 min)
```

**Benefit:** Prevents hammering down API repeatedly.

### 🎯 What Gets Fixed

| Problem | Old Behavior | New Behavior |
|---------|--------------|--------------|
| **Archive.org timeout** | Crash | Retry 8×, log failure |
| **Buzzsprout rate limit (429)** | Crash | Retry 6×, log failure |
| **Missing credentials (401)** | Crash (after retries) | Fail fast (no retries) |
| **API down (circuit breaker)** | Hammer API 10+ times | Breaker opens after 3 failures |
| **Upload fails** | Stop entire pipeline | Log failure, continue pipeline |
| **Recover failed upload** | Re-run entire pipeline | `python retry_failed.py --retry 0` |
